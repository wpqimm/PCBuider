# PCBuilder

Desktop-приложение для подбора и сравнения комплектующих ПК.
Создано в учебных целях как портфолио Junior Java Developer.

## 🚀 Функции
- Каталог товаров с категориями и подкатегориями
- Навигация через SlideBar и карточки категорий
- Окно сравнения товаров (по типу DNS)
- Тёмная фиолетовая тема, кастомные панели с 3D-эффектом (RoundedPanel)
- Разделение логики на модули: CatalogPanel, SubCategoryPanel, ProductDataFactory

## 🛠️ Стек
- Java
- Swing
- Git

## 🖥️ Как запустить
1. Склонировать репозиторий: `git clone https://github.com/твой_username/PCBuilder.git`
2. Открыть проект в IntelliJ IDEA
3. Запустить класс `Main`
